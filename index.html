免費 AI 遊戲設計工具技術文件

適用對象：國小自然科教師、資訊社團教師、想用 AI 快速製作教學小遊戲的教育工作者。

文件目的 工具比較 建議流程 Prompt 範例 部署建議 教學應用 檢核表

一、文件目的

本文件整理目前適合用於「免費或有免費額度」的 AI 遊戲設計工具，並提供教師在自然科、科展、創客課程、資訊社團中使用的建議流程。 目標不是一次做出大型商業遊戲，而是快速完成可以上課、展示、部署到網頁的小型互動遊戲。

核心建議：老師可使用 ChatGPT、Gemini、Claude 產生 HTML / CSS / JavaScript 小遊戲，再透過 Replit 或 GitHub Pages 測試與部署；學生可先從 Scratch、CreatiCode、GDevelop 入門。

二、免費 AI 遊戲設計工具比較

工具名稱 免費狀況 主要特色 適合對象 建議用途
Scratch 免費 積木式程式設計，適合初學者。 國小三至六年級學生 迷宮遊戲、接物遊戲、問答遊戲、互動動畫。
CreatiCode 有免費功能 類似 Scratch，加入 AI 與 3D 功能。 高年級學生、社團學生 AI 互動、3D 教學模擬、創意程式作品。
GDevelop 免費、開源，有部分雲端限制 免寫程式的遊戲引擎，可做完整 2D 遊戲。 教師、進階學生 平台跳躍、闖關、迷宮、射擊、任務型遊戲。
ChatGPT / Gemini / Claude 有免費版或免費額度 可協助設計遊戲規則、產生程式碼、修正 Bug。 教師、進階學生 產生 HTML5 小遊戲、設計題庫、撰寫部署說明。
Google AI Studio / Gemini Canvas 通常有免費額度 可將文字描述轉成互動網頁、遊戲雛形或 App 原型。 教師 快速製作互動教材、自然科小遊戲原型。
Replit 有免費方案 / 免費額度 瀏覽器即可寫程式、測試與分享作品。 教師、學生社團 測試 HTML / JavaScript 遊戲、保存專案、分享連結。
Rosebud AI 可免費試用 / 免費創作限制依平台而定 用文字生成可玩的 2D / 3D 遊戲原型。 教師、創意發想者 快速把教學遊戲想法變成可玩的雛形。
Construct 3 有免費版限制 拖拉式 2D 遊戲製作工具。 教師、學生社團 接物、闖關、平台跳躍、物理小遊戲。
Godot Engine 完全免費、開源 專業 2D / 3D 遊戲引擎。 進階學生、教師專案 完整遊戲專案、進階互動模擬。
Roblox Studio 免費 可製作 3D 世界與多人互動遊戲。 高年級學生、社團 3D 闖關、科學探索場景、校園虛擬世界。
提醒：「免費」通常代表有使用次數、專案數、匯出功能或雲端部署限制。正式教學使用前，建議先測試帳號、匯出方式與學生登入需求。

三、教師製作 AI 教學遊戲的建議流程

設定教學主題

先確定遊戲要對應的自然科概念，例如磁力、電路、昆蟲旅館、食蟲植物、風力發電。

設計遊戲規則

決定玩家目標、操作方式、得分方式、失敗條件與過關條件。

用 AI 產生原型

請 AI 產生單一 HTML 檔，包含 HTML、CSS、JavaScript，方便測試與部署。

本機或 Replit 測試

打開 index.html 測試遊戲是否可玩，檢查按鍵、碰撞、分數、題目與畫面。

修改與美化

加入可愛角色、音效、關卡、題庫、提示語、重新開始按鈕。

部署與分享

可部署到 GitHub Pages、Gitee Pages、Replit 或學校網站。

四、可直接使用的 Prompt 範例

Prompt 1：產生 HTML5 小遊戲

請幫我設計一款國小自然科教學用 HTML5 小遊戲。

遊戲名稱：昆蟲旅館大冒險
對象：國小五、六年級
主題：獨居蜂、巢管選擇、校園生態

玩法：
1. 玩家控制一隻可愛的獨居蜂。
2. 要選擇合適的巢管入住。
3. 不同巢管有不同管徑、深度、材質。
4. 選對會加分，選錯會出現提示。
5. 每一關加入一題自然科選擇題。
6. 請用 HTML、CSS、JavaScript 寫成單一 index.html 檔案。
7. 畫面要可愛，適合國小學生，並可部署到 GitHub Pages。

Prompt 2：請 AI 修正遊戲 Bug

以下是我的 HTML 遊戲程式碼。
請幫我檢查：
1. 為什麼角色無法移動？
2. 為什麼碰撞判定不準？
3. 為什麼分數沒有增加？
4. 請直接輸出修正版完整 index.html。

Prompt 3：加入自然科題庫

請幫我在這個遊戲中加入 10 題國小自然科選擇題。
主題：磁力與生活中的力。
每題四個選項，答對加 10 分，答錯顯示提示。
題目口吻要適合國小四年級學生。

Prompt 4：改成 GitHub Pages 可部署版本

請將這個遊戲整理成 GitHub Pages 可部署版本。
請提供：
1. index.html
2. README.md
3. 部署步驟
4. 如何修改遊戲標題、題目與圖片的說明。

五、部署建議

部署方式 優點 限制 適合情境
GitHub Pages 免費、穩定、適合展示作品。 需要基本 GitHub 操作。 老師作品集、學生專題、教學遊戲網站。
Gitee Pages 適合某些網路環境，操作類似 Git 平台。 功能與審核限制可能變動。 備用部署平台。
Replit 瀏覽器即可測試與分享。 免費方案資源有限。 快速測試、課堂展示、學生練習。
本機開啟 index.html 最簡單，不需上網部署。 不方便分享給全班。 教師備課、初步測試。

GitHub Pages 基本流程

  1. 建立新的 GitHub Repository。
  2. 上傳 index.html。
  3. 進入 Settings → Pages。
  4. 選擇 Branch：main，Folder：/root。
  5. 儲存後等待產生網址。

八、推薦使用路線

路線 A：老師快速備課

ChatGPT / Gemini / Claude → 產生 HTML 小遊戲 → Replit 測試 → GitHub Pages 發布 → 課堂使用。

路線 B：學生資訊社團

Scratch 入門 → CreatiCode 加入 AI 或 3D → GDevelop 製作正式闖關遊戲 → 成果發表。

路線 C：科展或專題延伸

先用 AI 設計互動模擬 → 加入實驗變因與數據 → 讓學生透過遊戲理解研究假設、變因控制與結果判讀。

最推薦入門組合：ChatGPT 或 Gemini + 單一 index.html + Replit / GitHub Pages。這種方式最容易保存、修改、分享，也最適合教師快速製作教材。
